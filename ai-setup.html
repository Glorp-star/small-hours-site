One-time setup

Connect Gemini
the safe way.

The builder needs a small private backend. You keep the API key in Cloudflare; it never goes in the public website or this chat.

Create a Gemini API key

Sign in to Google AI Studio and create a key for a project with Gemini API access. Keep the key private.

Start with the free tier and leave paid billing off. Free-tier limits apply, and Google may use free-tier prompts to improve its products.

Deploy the private backend

  1. Create or sign in to a Cloudflare account.
  2. Install Node.js if it is not already installed.
  3. Open a terminal in this project folder and run:
npx wrangler login
npx wrangler deploy

Add the Gemini key as a private Worker secret. Paste it only into the terminal prompt:

npx wrangler secret put GEMINI_API_KEY

Copy the Worker URL shown by Wrangler. It will look like https://small-hours-ai.YOUR-SUBDOMAIN.workers.dev.

Connect the website

In ai-config.js, set the public Worker URL and add /api/generate:

window.SMALL_HOURS_AI_CONFIG = Object.freeze({
  endpoint: "https://small-hours-ai.YOUR-SUBDOMAIN.workers.dev/api/generate",
});

Commit and push that configuration change to main. The endpoint URL is public; the API key is not.

Keep private information out.

The business name, description, services, area, and creative brief go to Gemini only after the user checks consent. Contact email and phone stay in the browser. Do not enter sensitive information.
